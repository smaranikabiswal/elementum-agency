# Reflection — Elementum Frontend Assignment

**Author:** Smaranika Biswal  
**Assignment by:** TRAMS  
**Time taken:** ~14–16 hours

---

## What I Built

A frontend recreation of the Elementum agency website from a Figma design provided by TRAMS. The project involved translating a detailed design into a fully functional, responsive React application.

---

## What I Learned

- How to break down a complex Figma design into reusable React components
- Using Intersection Observer for scroll-triggered animations
- Positioning and layering elements with Tailwind CSS
- Working with SVG paths to create custom decorative elements
- Exporting and managing image assets from Figma into a React project

---

## Challenges I Faced

- **Orange underline stroke** — Replicating the exact hand-drawn double-stroke SVG underline from the Figma design was the most difficult part. Getting the shape, position, and size to match precisely took significant trial and error.
- **Red decorative curves** — Matching the exact position and curvature of the red SVG line elements across different sections was tricky, especially making them responsive.
- **Asset management** — Learning the correct workflow to export images from Figma and integrate them into the project was a new process for me.

---

## What I Would Do Differently

- Start with a closer look at all the SVG decorative elements before writing any code, to plan them more carefully upfront
- Set up a consistent design token system for colors and font sizes earlier in the project
- Break components into smaller pieces from the beginning rather than refactoring later

---

## Overall

This was a challenging but rewarding experience. It pushed me to think carefully about design accuracy, CSS positioning, and component structure. I enjoyed bringing the design to life and learned a lot along the way.
