# Elementum — Frontend Agency Landing Page

A pixel-perfect frontend implementation of the Elementum agency website based on the provided Figma design. Built using React, Tailwind CSS, and Vite.

## 🛠 Tech Stack

- React
- Tailwind CSS
- Vite
- JavaScript (ES6+)
- Intersection Observer API

---

## ✨ Features

- Pixel-perfect implementation matching the provided Figma design
- Fully responsive layout optimized for desktop, tablet, and mobile devices
- Scroll-triggered animations using the Intersection Observer API
- Reusable and modular component architecture
- Custom SVG decorative elements inspired by the original design
- Floating avatar animations with staggered effects
- Testimonials carousel with smooth transitions
- Interactive hover effects throughout the interface
- Clean and maintainable project structure

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/smaranikabiswal/elementum-agency.git
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
